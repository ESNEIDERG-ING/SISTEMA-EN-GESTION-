# Visión del proyecto Sistema en Gestión

## Propósito

Sistema en Gestión es un proyecto de software orientado a facilitar la gestión y organización de la información de una organización mediante una solución tecnológica centralizada.

El sistema busca mejorar el manejo de la información, facilitar el seguimiento de los procesos y proporcionar una herramienta que permita consultar y administrar los datos de manera organizada.

## Objetivo general

Desarrollar un sistema de gestión que permita administrar información y procesos de manera estructurada, facilitando el acceso a los datos y apoyando las actividades de los usuarios.

## Objetivos específicos

- Organizar la información del sistema de manera estructurada.
- Facilitar la gestión y consulta de los datos.
- Implementar funcionalidades de acuerdo con las necesidades definidas en las Historias de Usuario.
- Aplicar buenas prácticas de desarrollo de software.
- Mantener una estructura de código organizada y fácil de mantener.
- Utilizar control de versiones mediante Git y GitHub.
- Aplicar un flujo de trabajo basado en ramas y Pull Requests.
- Documentar los principales componentes y decisiones del proyecto.

## Alcance

El proyecto contempla el desarrollo progresivo de las funcionalidades definidas en el backlog.

El alcance puede ampliarse durante las diferentes etapas del proyecto de acuerdo con las necesidades identificadas y las prioridades establecidas por el equipo.

## Usuarios

El sistema estará orientado a los usuarios definidos en los requerimientos del proyecto, quienes podrán interactuar con las funcionalidades desarrolladas de acuerdo con los permisos y responsabilidades establecidos.

## Visión a futuro

Se busca que Sistema en Gestión pueda evolucionar progresivamente mediante la incorporación de nuevas funcionalidades, mejoras de seguridad, optimización del rendimiento y una experiencia de usuario cada vez más completa.
