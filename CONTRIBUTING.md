# Contribución al proyecto Sistema en Gestión

## Objetivo

Este documento establece las normas básicas para contribuir al desarrollo del proyecto Sistema en Gestión.

## Flujo de trabajo

1. Crear una rama para la funcionalidad o corrección que se va a desarrollar.
2. Realizar los cambios correspondientes.
3. Probar la funcionalidad desarrollada.
4. Realizar un commit siguiendo las convenciones establecidas.
5. Subir la rama al repositorio remoto.
6. Crear un Pull Request.
7. Solicitar la revisión de otro integrante del equipo.
8. Corregir las observaciones realizadas durante la revisión.
9. Integrar los cambios cuando el Pull Request sea aprobado.

## Convención para ramas

Se recomienda utilizar los siguientes formatos:

- `feature/nombre-funcionalidad`
- `bugfix/nombre-error`
- `hotfix/nombre-correccion`

```text
feature/login
feature/registro-usuario
feature/gestion-productos
bugfix/error-validacion
