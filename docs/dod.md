# Definition of Done (DoD)

Una Historia de Usuario se considera terminada cuando cumple con los siguientes criterios:

- [ ] El código cumple con los estándares definidos para el proyecto.
- [ ] La funcionalidad implementada cumple los criterios de aceptación.
- [ ] El código ha sido revisado mediante Pull Request.
- [ ] Las pruebas correspondientes han sido realizadas.
- [ ] No existen errores críticos conocidos.
- [ ] La documentación necesaria ha sido actualizada.
- [ ] Los cambios cumplen las convenciones de commits establecidas.
- [ ] La funcionalidad está integrada correctamente en la rama correspondiente.
- [ ] El Pull Request ha sido aprobado por otro integrante del equipo.
- [ ] La funcionalidad está lista para ser presentada o entregada.
